# Gallery Configuration API Reference

All gallery configuration classes live in `dj_design_system.gallery`. Use `GalleryConfig` and `Variant` to configure component metadata, navigation hierarchy, canvas rendering, and variations.

::: dj_design_system.gallery
    options:
      members: true
      show_root_heading: false
      show_source: true
      show_symbol_type_heading: true
      show_symbol_type_toc: true
      docstring_style: google
      merge_init_into_class: true
      group_by_category: true
