# Product Definition

## Vision
dj-design-system (DjDS) provides a Django-native approach to writing front-end components. It aims to bridge the gap between Django development and modern UI component systems by offering templatetag-exposed components and an auto-generated, live interactive gallery for discovery and documentation.

## Core Value Proposition
- **Native Django Experience:** Components look and work like standard Django Models or Forms.
- **Automated Gallery:** Discovers components, renders live previews in isolated sandboxes, and auto-generates documentation and usage examples.
- **Developer Productivity:** Enables robust UI development tightly integrated with existing Django projects without relying on heavy JS frameworks.

## Target Audience
- Django developers building complex UIs who prefer server-side rendering.
- Teams needing a shared, interactive component library integrated with their Django backend.
