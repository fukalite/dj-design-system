# Navigation

Everything that gets you around the gallery:

- **SearchBox** and **NavTree** fill the sidebar.
- **Breadcrumb** shows where the current page sits.
- **FolderListing** lists a folder's contents on its default page.
- **Tabs** switch between the documentation and sandbox panes on narrow screens.
- **ThemeSelect** picks the gallery theme.

These are internal components: their parameters and markup may change without a deprecation period.
