# Layout

The gallery's frame and the containers inside it.

**GalleryShell** holds the **Sidebar** and the main area, with the **Toolbar** across its top and the **MobileMenuToggle** for narrow screens. Standalone pages such as this one use **Page**, and long-form text uses **Prose**. A component's page is a **SplitPane** of two **Pane**s: documentation and sandbox.

These are internal components: their parameters and markup may change without a deprecation period.
