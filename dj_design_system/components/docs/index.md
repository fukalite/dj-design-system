# Docs

The parts of a component's documentation pane that are generated from the component itself:

- **UsageExample** shows a template tag example with an optional live preview.
- **ParamsTable** lists the component's parameters, their types, defaults and descriptions.
- **VariantView** focuses the pane on one of the component's gallery variants.

These are internal components: their parameters and markup may change without a deprecation period.
